永远记不住的ta们

可以直接用 =（赋值运算符） 进行深拷贝。

vector

  • 动态数组，支持随机访问。
  • 尾部插入 / 删除高效（均摊 O (1)），中间插入 / 删除较慢（O (n)）。
  • 内存连续，可能需要重新分配内存（导致元素复制）

deque

  • 双端队列，支持头尾高效插入 / 删除（O (1)）。
  • 随机访问效率略低于vector。
  • 内部由多个固定大小的数组组成，避免了vector的内存重分配问题。

list

  • 双向链表，任意位置插入 / 删除高效（O (1)）。
  • 不支持随机访问（只能顺序遍历）。
  • 内存不连续，每个元素包含前后指针。

set

  • 有序集合，元素唯一，基于红黑树实现。
  • 插入、删除、查找均为 O (log n) 时间复杂度。
  • 元素自动按升序排列（可自定义比较函数）。(从小到大)

map

  • 有序键值对，键唯一，基于红黑树实现。
  • 插入、删除、查找、单点访问均为 O (log n) 时间复杂度。
  • 元素按键升序排列。

multiset multimap

  • 允许重复元素或键，其他特性与set和map相同

unordered_set

  • 无序集合，元素唯一，基于哈希表实现。
  • 平均 O (1) 时间复杂度的插入、删除、查找。
  • 内存占用较大，且可能需要重新哈希（rehash）。

unordered_map

  • 无序键值对，键唯一，基于哈希表实现。（不建议使用 极大可能被特定数据卡掉）
  • 平均 O (1) 时间复杂度的插入、删除、查找。

stack

  • 后进先出（LIFO）栈，默认基于deque实现。
  • 只允许在栈顶操作。

queue

  • 先进先出（FIFO）队列，默认基于deque实现。
  • 支持队首出队、队尾入队。
  • 没有q.clear()

priority_queue

  • 优先队列，最大 / 最小元素优先出队，默认基于vector和堆实现。
  • 默认按元素值降序排列（大的在队首）。
  • 无法直接查找元素

所有容器都支持以下操作：

  • begin(), end()：返回指向首尾元素的迭代器。
  • rbegin(), rend()：返回指向首尾元素的反向迭代器。
  • empty(), size()：判断容器是否为空、返回元素个数。
  • clear()：清空容器

1. 基本运算符

  • 按位与（&）：两对应位都为 1 时结果为 1，常用于清零或取特定位。
    例：5 & 3 = 1（二进制：101 & 011 = 001）。
  • 按位或（|）：两对应位有一个为 1 时结果为 1，常用于置位。
    例：5 | 3 = 7（二进制：101 | 011 = 111）。
  • 按位异或（^）：两对应位不同时结果为 1，常用于取反或交换。
    例：5 ^ 3 = 6（二进制：101 ^ 011 = 110）。
  • 按位取反（~）：对每一位取反，常用于生成掩码。
    例：~5 = -6（二进制：~0101 = 1010，补码表示为 - 6）。
  • 左移（<<）：将二进制位左移，低位补 0，等价于乘以 2 的幂。
    例：5 << 1 = 10（二进制：101 → 1010）。
  • 右移（>>）：将二进制位右移，高位补符号位（算术右移）或 0（逻辑右移），等价于除以 2 的幂。
    例：5 >> 1 = 2（二进制：101 → 10）。

2. 常见用途

  • 判断奇偶：n & 1 为 1 则奇数，为 0 则偶数。
  • 交换两数：a ^= b; b ^= a; a ^= b;。
  • 取绝对值（补码系统）：(n ^ (n >> 31)) - (n >> 31)。

埃氏筛

从最小的质数（2）开始，依次将每个质数的倍数标记为非质数。对于每个质数 p，需要标记的倍数是 2p, 3p, ..., ⌊n/p⌋·p，共 ⌊n/p⌋ - 1 个数。

其时间复杂度的推导基于调和级数的近似：

  • 筛选过程中，对每个质数 p 的操作次数约为 n/p。
  • 所有质数的 1/p 之和近似为 log log n（这是数论中的一个经典结论）。
  • 因此，总操作次数约为 n log log n。
