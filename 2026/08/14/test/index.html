摘要

第三章

BCD码：用二进制表示十进制数的编码方式

逻辑移位针对无符号数、算数移位针对有符号数（移的时候不移符号）

关于算术左移右移

算数左移（* 2）：原码补码无论正负，均为低位补0
算数右移（/ 2）：原码补码先看符号位，正补0 负补1
原码补码规则是相同的

ALU的核心部件是加法器

补码减法会用==进位置0==来替代转换补码时的==末位加一==

关于乘法的一些概念

快速阵列乘法没有移位器，同时算出所有位的答案然后并行求和。
一位乘法（原码一位乘法）指的是每次乘法指处理1个二进制位。相应的：还有两位乘法
BOOTH算法（补码一位乘法）：直接用补码完成正负数/小数乘法，不用单独处理符号
移位方式：原码-逻辑右移 补码-算数右移

设乘数寄存器最低位是Yn​，额外增设 1 位附加位Yn+1​，初始为 0；每次循环判断这两位：

组合 Yn ​Yn+1​ 操作（部分积）
0 0 不加，直接算术右移一位
0 1 加 【X】补，再算术右移一位
1 0 加 【-X】补，再算术右移一位
1 1 不加，直接算术右移一位
每一次整体右移：
  • Q 内部所有位向右挪 1 格；
  • Q 最右侧的最低位 Q0​ 挤出去，变成新的 Yn+1​；
  • A 寄存器移出的最低位，填入 Q 最左侧空位；

1字节（Byte）=8bit

有符号int的字节数为4，共有4 * 8个二进制位，范围$-2^{31} \sim 2^{31} - 1$
bit代表一个二进制位，寄存器位数、地址位等
Byte是编址单位，是KB/MB/GB的单位

IEEE754单精度浮点数（float）表示格式

【1：正负】【8：阶码】【23：尾数】
转为二进制后例： $(1.10\cdots0)_2 \times 2^{-1}$
正负为0
阶码为 -1+127 （移码）
尾数为10…0
阶码的表示范围为-127~128 对应0~255

常见数据类型

char：1字节
short：2字节
int：4字节
longlong：8字节
float：4字节（1+8+23）

第四章

相对寻址的位移量用补码表示

MSB：最高有效位 LSB：最低有效位

第五章

PC中存放的是指令在==主存==中的地址

指令顺序执行后，PC的值增加一条指令的长度（字节/字）

IR中存放的是当前指令（操作码+地址字段）

CPU 分为 数据通路和控制单元

数据通路：执行数据操作

  • 状态元件：寄存器、PC、IR
  • 操作元件：ALU、加法器、移位器

控制单元：逻辑电路，输出控制线

CPI：==每条指令时钟周期数==

$T_{\text{cycle_total}} = N \times \text{CPI}$ （时钟周期=指令数* CPI）
$Time = \dfrac{T_{\text{cycle_total}}}{\text{主频 } f} = \dfrac{N \times \text{CPI}}{f}$ （程序运行时间=时间周期/主频）

单周期cpu和多周期cpu

单周期数据通路

一条指令占1个时钟周期（时钟周期由最慢的指令决定/CPI=1）
不需要IR，指令直接在线路上传输

多周期数据通路

一条指令占多个时钟周期
需要IR
硬件利用率高

R型指令：寄存器型指令

所有操作数、运算结果全都存放在通用寄存器，不访问内存，均要使用ALU
OP(6) | Rs(5) | Rt(5) | Rd(5) | shamt(5) | funct(6)
取Rs和Rt做funct运算==存入Rd==中（OP均为0，shamt是移位量 仅移位指令使用）

I型指令：立即数型指令

访存、算术立即、逻辑立即、分支
lw：load访指令，sw：save存指令，beq：branch_if_equal
OP(6) | Rs(5) | Rt(5) | imm16(16)
OP指令，Rs基址/==源操作数==1，Rt目标寄存器/比较数2，imm16立即数

一些MIPS指令

add rd,rs,rt：$rd = $rs + $rt，溢出报错
addi rt,rs,imm：$rt = $rs + 立即数（有符号）
lw rt, off($rs)：字加载，从内存地址rs+off读 32 位到 rt
beq rs, rt, label：若 $rs == $rt，跳转到 label
bne rs, rt, label：若 $rs != $rt，跳转到 label
sll rd,rt,shamt 逻辑左移：$rd = rt << shamt（补 0）

第六章

采用流水线方式会延长一条指令的执行时间，但总的时间会节约
加倍的增加流水线个数 不能 成倍提高指令执行效率

（实际吞吐率受冲突限制）

组合逻辑部件：ALU、加法器、译码电路。时序逻辑部件：流水寄存器
数据冒险：后面指令用到的数据还未来得及由前面数据产生

采用 转发（旁路） 技术可以解决部分控制冒险

控制冒险：转移指令或异常等情况改变了程序处理的流程，使已经被取到流水线中的指令无效

采用分支预测技术 可用于控制冒险处理

关于一点单位

$1ps=10^{3}nm=10^{6}μs=10^{9}ms=10^{12}s$

第七章

在计算机底层的内存容量换算方法：

$1GB=2^{10}MB=2^{20}KB=2^{30}B$

我应该认识你们吧

RAM：随机访问存储器

  • SRAM：静态ram 速度快 用作cache 成本高
  • DRAM：动态RAM 读后需要再生 动态刷新 ==行列地址复用==（RAS行地址选通 CAS列地址选通）
    ROM：只读存储器
    EPROM：可擦除可编程 只读存储器
    CAM：相联存储器（按照内容进行寻址访问）
RAID

将多块物理硬盘组合为一个逻辑硬盘阵列
目标：提升读写性能、数据冗余容错、扩容

CRC校验（循环冗余校验）
  1. 将生成多项式转二进制，位数为r+1
  2. 在原数据后面补 r 个0，除以 生成多项式的二进制数（模2除法/异或）。
  3. 把余数添加到原数据后面，发送
  4. 校验时将得到的数除以 生成多项式的二进制数 看余数是否为0
地址转换

地址转换是将逻辑地址转换为物理地址
逻辑地址的位数比物理地址更多
目的：- 隔离进程地址空间；实现内存离散分配、虚拟内存（换入换出）；内存共享、地址保护

若Page未命中 Cache也一定未命中

（TLB是否命中不构成矛盾。TLB：快表（转换后援缓冲器）。内置于==CPU中== 缓存近期使用的{页号-页框号/虚拟地址和物理内存}映射）

每一个进程都有一个页表。进程被划分为等长的页、内存被划分为相同大小的页框
段式存储管理

程序按逻辑模块划分为段（代码段、数据段、栈段，长度不固定）；
每个段拥有独立段号、段长度。
段式存储管理相比于分页式更利于存储保护

主存地址总位数 = Tag 位 + 组索引位 + 块内偏移位

  • 块内偏移：log2​(块字节数)
  • 组索引：log2​(组数)=log2​(总块数/相联路数)
  • Tag：剩余高位
    Cache 总容量 = 数据存储位 + Tag+control位
