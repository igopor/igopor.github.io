第一章 概述

计算机网络是现代计算机技术和通信技术密切结合的产物
三网合一是 电信网、广播电视网、互联网 的融合

互联网两个核心基本特点：

  • 无连接、分组交换
    数据拆分为独立分组传输，分组独立选路，不预先建立全程通路，容错性强。
  • 采用 TCP/IP 协议簇，异构网络互联
    统一 IP 协议屏蔽各类局域网、广域网底层差异，实现不同结构网络互通。

计算机网络由网络硬件（主机、传输介质、网络互联设备）和网络软件（网络协议、网络操作系统、网络应用程序）共同组成。

计算机网络按网络的作用范围可分为 局域网（LAN/local）、城域网（MAN/metropolitan）、广域网（WAN/wide）

网络协议三要素：语法（怎么传）、语义（传什么含义）、时序（何时传、快慢如何）

协议和服务
  • 服务：下层向上层提供的功能调用，垂直层间使用，用户可见；
  • 协议：同一层级对等实体通信规则，水平对等层使用，上层不可见。
TCP/IP 四层模型（由高到低）：

应用层、传输层、网络层、网络接口层（物理层+数据链路层）

OSI 七层模型：

应用层（为应用程序提供网络交互服务）、表示层、会话层、传输层（端到端进程通信）、网络层（主机到主机跨网络寻址与分组转发）、数据链路层（同一相邻节点间透明传输帧）、物理层（传输比特流）

（学校折中教授了五层模型）

计算机网络的功能：

数据通信、资源共享、分布式处理、提升可靠性、负载均衡、综合信息服务

比较网络的区别可以从：

覆盖范围、传输速率、传输延迟、拓扑结构、核心设备、所有权等角度

计算机网络体系分层的原因
  • 模块化独立
  • 便于开发维护
  • 标准化互通
  • 简化问题
  • 易于扩展
一些交换技术
  • 电路交换：通信前独占物理专线，传统固定电话。
  • 报文交换：把消息作为一份报文，存下报文再转发
  • 分组交换：把报文切割为短分组，存下分组再转发
    分组交换有两种工作方式：虚电路（先建通路、天然有序）和数据报（无需通路，路由选择）。
各层的数据单元
  • 应用层：报文/消息
  • 传输层：报文段、用户数据报
  • 网络层：IP数据报（分组）
  • 数据链路层：帧
  • 物理层：比特
四大时延（单位是秒）
  • 发送时延（传输时延）
  • 传播时延
  • 处理时延
  • 排队时延
从逻辑功能上看，计算机网络可以分为 通信子网 和 资源子网 两部分

计算题会用到的单位换算：
\begin{align*} 1\ \text{Kbps} &= 1000\ \text{b/s} \ 1\ \text{Gb/s} &= 1000\ \text{Mb/s} \ 1\ \text{Mb/s} &= 1000\ \text{kb/s} \ 1\ \text{B} &= 8\ \text{b} \end{align*}

第二章 物理层

四大接口特性

  1. 机械特性：规定硬件接口物理外形、尺寸、引脚数量等
  2. 电气特性：规定电平电压、信号幅值
  3. 功能特性：每一根引脚的作用
  4. 规程特性（过程特性）：规定交互的时序和流程
数据通信系统三大组成:源系统、传输系统、目的系统。

计算机网络中常用的三种有线通信介质是 双绞线（屏蔽双绞线、非屏蔽双绞线）、同轴电缆(有线电视)、光纤（单模光纤、多模光纤）

将数字数据调制为模拟信号的调制方法：振幅调制、频率调制、相位调制

在10Base-T总线网（星型）中，最大传输距离是100m

多路复用技术（将两个或多个彼此独立的信号合并为一个复合信号，在一条公用信道上传输的方法。可以充分利用信道带宽，降低通信成本）
  • 频分多路复用FDM：将信道频段划分为独立子频段，每路信号独占一个频段，同步并行传输
  • 时分多路复用TDM：划分传输时间
  • 波分多路复用WDM：光波长
  • 码分多路复用CDM（CDMA）：正交编码区分信号
通信方式 在信道传输方向上 分为：单工通信(永远单向)、半双工通信（可以双向 但不能同时双向）、全双工通信（可以同时双向）

同步传输：传输完整数据帧，时钟必须严格同步。异步传输：传输单个字符，字符自带起止位

香农公式

C = W \cdot \log_2\left(1 + \frac{S}{N}\right)其中
C：信道容量（最大传输速率 bit/s）
W：信道带宽（Hz）
S：信号功率 N：噪声功率 S/N：信噪比
当信噪比以分贝（dB）单位给出时：通过公式 \text{SNR}(\text{dB}) = 10\lg_{10}\frac{S}{N}计算出S/N。

奈奎斯特公式/奈式准则（无噪声信道）

C = 2W \log_2 M其中
C：信道容量（最大传输速率 bit/s）
W：信道带宽（Hz）
M：码元的离散电平数（二进制数据为2）

用集线器连接的工作站集合 属于同一个冲突域，也属于同一个广播域

设备 工作层 隔离冲突域 隔离广播域
中继器 物理层 ❌ 否 ❌ 否
集线器 Hub 物理层 ❌ 否 ❌ 否
网桥 / 交换机 数据链路层 ✅ 是 ❌ 否
路由器 网络层 ✅ 是 ✅ 是
双绞线双绞原因：

互相绞合后，抵消两根线之间的电磁干扰，降低外界噪声对信号的影响，提升传输稳定性

数字数据模拟信道为什么需要调制

模拟信道无法直接传输数字，需把数字0/1加载到正弦模拟载波上才能传输。

波特率和比特率
  • 波特率（码元速率）
    单位：Baud（波特），每秒传输的码元个数。一个码元可以携带多个比特。
  • 比特率（信息传输速率）
    单位：bit/s，每秒传输的二进制比特（0/1）数量。

\text{比特率} = \text{波特率} \times \log_2 M 其中，M：一个码元可取的离散电平（状态）数量

CDMA相关计算

设码片长度为 n，本站码片序列S，接收混合序列X
内积运算：
\mathrm{sum} = S_1X_1 + S_2X_2 + \dots + S_nX_n,\quad \mathrm{result} = \dfrac{\mathrm{sum}}{n}
判断规则：

  1. result≈+1：该站点发送比特 1
  2. result≈−1：该站点发送比特 0
  3. result≈0：该站点未发送任何数据

第三章 数据链路层

网络拓扑

网络拓扑结构是指网络中计算机、交换机等节点与传输介质的几何连接布局，反映设备间物理或逻辑连接关系。
类型：星型、总线型、环型、树型、网状型。

数据链路层的三大基本问题：

  1. 封装成帧：前后添加首部、尾部标记，把网络层分组封装为帧。
  2. 透明传输：保证帧内任意二进制比特都能正常传输，不会误判帧结束位置
  3. 差错检测：检测传输过程中线路干扰造成的比特错误

Ethernet的核心技术是它的随机争用型介质访问控制方法，即CSMA/CD 载波监听多路访问 / 冲突检测：
概念：

  • CS：载波监听，发送前先听信道
  • MA：多路访问，多主机共享同一信道
  • CD：冲突检测，发送时边发边检测碰撞
    作用：
  • 协调多台主机共享同一广播信道，避免同时发送造成**数据冲突；
  • 冲突发生后自动退避重传，保障所有主机公平使用链路；
  • 是传统以太网（10BASE-T、100BASE-TX）的核心介质访问控制方法。
    工作原理：
  1. 载波监听（发前先听）
    主机准备发帧前，持续监听信道电平：
    • 信道空闲（无信号），立刻开始发送；
    • 信道忙（其他主机正在发），持续等待直至信道空闲。
  2. 边发边检测冲突（CD）
    主机发送帧的全过程，持续对比发送信号与线路实际信号：
    • 信号一致：无冲突，完整发完；
    • 信号不一致：检测到冲突。
  3. 冲突处理
    一旦检出冲突：
    ① 立即停止发送当前帧；
    ② 发送强化干扰信号（拥塞信号），通知所有主机信道发生冲突；
  4. 截断二进制指数退避算法（等待重发）
    所有冲突主机停止发送，随机等待一段时间后重试：
    • 第 k 次冲突，等待时间从 0∼2k−1 个时隙中随机选；
    • 冲突次数越多，等待时间范围越大，降低再次碰撞概率；
    • 冲突达到 16 次仍失败，丢弃该帧，上报上层。

局域网参考模型将数据链路层划分为MAC子层与LLC子层

循环冗余校验（CRC）：

仅检错，检错能力极强：可检测全部奇数错、大部分突发差错；
若 原始数据M=110101，生成多项式对应二进制G=1101，余数长度r=3（余数长度为G长度-1）

发送方：
  1. 补0：110101000
  2. 用110101000与G做模2除法（无借位减法），得到余数001
  3. 发送 110101001
接收方：
  1. 收到110101001
  2. 用110101001除以G，余数为0，无错
PPP协议（点对点协议）两种透明传输方案

异步传输使用字符填充法（0x7E），同步比特流传输使用零比特填充（位填充）。

MAC地址（硬件地址/物理地址）
  • 长度固定：48位/6字节
  • 全局唯一：每一块网卡的MAC地址不重复
  • 数据链路层使用：不能跨路由器，仅在同一个广播域/局域网内生效
  • 固化不可修改
VLAN（虚拟局域网）

三种常见划分方式

  1. 基于端口：把交换机端口固定划入 VLAN；
  2. 基于 MAC 地址：按设备硬件地址分配 VLAN，设备换端口不变 VLAN；
  3. 基于 IP / 子网：三层划分，三层交换机使用。
    作用
  • 隔离广播域，减少广播流量；
  • 逻辑分组，同一部门即使物理位置分散也属于同一局域网；
  • 提升网络安全，不同 VLAN 无法直接二层互访。
以太网交换机特点：
  • 工作在数据链路层，依据 MAC 地址转发帧；
  • 每个端口是独立冲突域（碰撞域），端口之间不会发生冲突；
  • 整机属于同一个广播域，广播帧会向所有其他端口转发；
  • 支持全双工通信，收发可同时进行，不再使用 CSMA/CD；
  • 内部维护 MAC 地址表，自动学习端口与主机 MAC 的映射，单播帧精准转发，不泛洪；
  • 物理拓扑星型，可划分 VLAN 切割广播域。
以太网交换机自学习

交换机内部维护一张MAC 地址表（<MAC 地址，对应端口>），无需人工配置，通过收到的帧自动记录 “哪个 MAC 从哪个端口发来”，后续单播帧精准转发，不用泛洪所有端口。

第四章 网络层

网络层的两个层面

  1. 数据平面：查询路由表，进行分组转发。
  2. 控制平面：运行路由协议，生成、维护路由表。
网络层的一些协议
  • 数据承载：IPv4、IPv6
  • 差错控制：ICMPv4、ICMPv6
  • 地址解析：ARP、NDP
  • 路由交换：RIP、OSPF、BGP（计算、生成并维护路由表，为 IP 分组选择从源到目的的最优转发路径，实现跨网络寻址转发。）
  • 安全加密：IPSec

IP地址分类（IPv4 地址32位）

  1. A类地址（大型公网）：首位固定0
    范围 0.0.0.0 ~ 127.255.255.255
    网络号 8，主机号 24
  2. B类地址（中型网络）：前两位固定10
    范围 128.0.0.0 ~ 191.255.255.255
    网络号 16，主机号 16
  3. C类地址（小型局域网）：前三位固定110
    范围 192.0.0.0 ~ 223.255.255.255
    网络号 24，主机号 8
  4. D类地址（组播通信）：前四位固定1110
    范围 224.0.0.0 ~ 239.255.255.255
    无网络主机号划分，用于IP组播（一对多传输）
  5. E类地址（保留实验）：前四位固定1111
    范围 240.0.0.0 ~ 255.255.255.255

CIDR

含义：无分类编址（抛弃传统分类，使用 IP 地址 / 前缀长度 表示网络）
优势：消除地址浪费、路由聚合（提升转发效率）、分配灵活、简化规则
计算：

eg：192.168.2.0/24
块大小：2^{32-24} = 256
网络地址：192.168.2.0
广播地址：192.168.2.255
可用主机：254台

什么是子网掩码

子网掩码是一个32位二进制数，用于区分IP地址中的网络位和主机位
网络部分写1，主机部分写0。
作用：将本机IP与子网掩码 按位与 得到子网网络地址。划分子网，避免地址浪费

ARP地址

实现IP 地址 → MAC 地址的映射解析
工作原理：

  1. 检查本地ARP缓存（找到就直接结束）
  2. 发送ARP请求帧
  3. 目标主机回复
  4. 更新缓存 正常发数据

ip数据报首部

IPv4 首部固定20字节（160位），可选字段最多40字节
TTL：行3 生存时间。每过一台路由器-1，TTL=0时丢弃
DF位：行2 标志的第二位。置1则禁止分片，包过大丢弃并返回ICMP
MF位：行2 标志的第三位。置1则后续还有分片，置0则为最后一片分片

关于分片

分片只会发生在路由器上，重组只能在目的主机上完成
以太网 MTU（最大传输单元）=1500字节，IP 首部 20 字节
除最后一个分片外，其余所有分片的数据长度必须是8 字节的整数倍
假设原始 IP 总长度 4000 字节：

  1. 分片 1：首部 20 + 数据 1480，总长度 1500
    MF=1，片偏移 = 0
  2. 分片 2：首部 20 + 数据 1480，总长度 1500
    MF=1，片偏移 = 1480÷8=185
  3. 分片 3：首部 20 + 剩余数据 940，总长度 960
    MF=0，片偏移 = (1480+1480)÷8=370

最长前缀匹配

  • 拿到数据包目的 IP；
  • 遍历路由表每一条：目的网络 + 掩码；
  • 目的 IP & 子网掩码，算出目标网络；
  • 若计算结果 = 表中目的网络，记为匹配条目；
  • 在所有匹配条目里，选出前缀 n 最大的一条；
  • 根据该条下一跳 / 接口转发；无匹配则丢弃。
路由选择协议
分类维度 类型 代表协议 使用范围
自治系统 IGP 内部网关 RIP、OSPF 单个 AS 内网
自治系统 EGP 外部网关 BGP4 AS（自治系统） 与 AS 之间
算法类型 距离矢量 DV RIP 小型网络
算法类型 链路状态 LS OSPF 大中型企业 / 运营商内网

RIP：

距离矢量 DV 类 IGP 内部网关协议
最大有效跳数：15；跳数 = 16 代表不可达。

NAT(网络地址转换)

NAT 部署在路由器出口（内网口 + 外网口），维护一张转换映射表，记录：内网私有 IP + 源端口 ↔ 公网 IP + 新端口。
作用：节省公网 IPv4 地址、隐藏内网主机提高安全、内网地址规划不受运营商限制；

第五章 传输层

作用

  • 进程间==端到端通信==
    网络层只区分主机 IP，运输层依靠端口号区分同一台主机内不同应用进程，实现程序对程序的数据传输。
  • 提供两类传输服务
    • TCP：面向连接、可靠传输；具备三次握手建立连接、流量控制、拥塞控制、差错重传、有序交付功能；适用于文件、网页等需要完整可靠数据的场景。
    • UDP：无连接、不可靠传输；开销极小，不拆分不合并，无额外校验与重传；适用于直播、语音通话、DNS 等实时业务。
  • 复用与分用
    发送端将多个应用进程的数据复用进 IP 报文；接收端根据端口号分发给对应程序。
  • 差错检测
    通过校验和检测报文数据损坏，丢弃出错报文（TCP 会重传，UDP 直接丢弃无补救）。

UDP特点：

无连接、不可靠交付、面向报文（不拆分）、开销小、无流量/拥塞控制、支持一对多、仅提供简单差错检测

TCP特点：

面向连接（传输前三次握手、传输后四次挥手）、可靠交付、面向字节流、同时收发数据（仅TCP）、有流量/拥塞控制、首部开销可变

套接字（Socket）

TCP 连接的端点叫做套接字，格式：IP 地址：端口号
完整标识：(源IP, 源端口, 目的IP, 目的端口)，主机和应用进程绑定， 唯一确定一条 TCP 连接。
不同连接只要四元组不完全相同，就是独立连接；

TCP报文段

数据偏移：首部字节数=数据偏移值* 4，首部后面就是数据部分
序号：本报文段第一个数据字节的编号（单位为字节）
确认号：32位，当ACK=1时有效。值为 期望收到对方下一个字节的序号
窗口：表示发送该报文的接收窗口还可接收多少字节的数据量

TCP滑动窗口

目的：
实现流量控制：防止发送方发太快，接收方缓冲区溢出丢数据
同时提升效率，不用发一段等一段，可连续批量发送
窗口划分：

  • 已发送、已确认：窗口左侧，完全安全，可丢弃；
  • 已发送、未确认：窗口内部左侧，等待 ACK；
  • 允许发送但还未发送：窗口内部右侧，可立刻发；
  • 不允许发送：窗口右侧，超出接收方承载能力。

TCP超时重传

往返时间 RTT：发送报文到收到对应 ACK 的时间。
普通算法：
TCP 持续采样每次真实 RTT，平滑计算出加权平均往返时间 RTTₛ，再加上波动偏差 RTTᴰ，算出超时计时器 RTO。
（缺陷：报文丢失、ACK 延迟会触发重传，导致RTO 计算不准）
Karn算法：
发生超时重传，下一次的 RTO 直接翻倍；只有未重传、一次就收到 ACK的报文，才拿它的 RTT 去平滑更新 RTT 参数。
（作用：避免重传混淆带来的 RTT 测量错误；网络拥堵丢包时，通过 RTO 翻倍放慢发送节奏，缓解拥塞。）

TCP流量控制

作用：防止发送方发送速率过快，超出接收主机缓冲区容量，导致接收方缓存溢出、报文丢失。保障发送速度匹配接收方处理能力。
原理：滑动窗口（连续ARQ）

TCP拥塞控制

作用：防止发送方注入网络的数据过多，造成路由器缓存溢出、大范围丢包、网络瘫痪；调节发送速率，匹配网络承载能力
原理：发送方维护拥塞窗口 cwnd（发送端本地内存变量），结合接收窗口 rwnd（收到的报文中），真实发送窗口 = min (cwnd, rwnd)。
通过丢包、延迟判断网络拥塞程度，动态增大 / 缩小 cwnd：
四种算法：
慢启动（Slow Start）(骗你的 一点也不慢)

  1. 初始 cwnd = 1（1 个 MSS 最大报文段）
  2. 每收到 1 个 ACK，cwnd += 1；一个 RTT 窗口直接翻倍，指数增长
  3. 设置慢启动阈值 ssthresh：
    cwnd < ssthresh → 慢启动；
    cwnd ≥ ssthresh → 切换拥塞避免。

拥塞避免（Congestion Avoidance）

  1. cwnd ≥ ssthresh 进入此阶段
  2. 每经过一个完整 RTT，cwnd += 1；线性缓慢增长，避免暴涨造成拥塞。

快重传（Fast Retransmit）
触发条件：收到3 个重复 ACK，判定报文丢失（不等超时计时器到期）
动作：

  1. 立即重传丢失报文，不用等待超时；
  2. 更新 ssthresh = cwnd / 2；
  3. cwnd = ssthresh，直接进入快恢复。

快恢复（Fast Recovery）
配合快重传使用：
4. 收到 3 个冗余 ACK 后，ssthresh = cwnd/2，cwnd = ssthresh
5. 每收到一个重复 ACK，cwnd += 1，继续发送新报文
6. 收到缺失报文的确认 ACK，退出快恢复，进入拥塞避免。

第六章 应用层

DNS（域名系统）

域名 ↔ IP 地址相互解析

域名

域名是互联网上用于标识一台或多台主机、服务器的字符型名称，用来替代难以记忆的数字 IP 地址，不区分大小写，层级最多 127 层，总长度不能超过 253 字符；
域名采用倒树分层，最右侧是最高层级，每一层用.点分隔，层级从右至左依次缩小：www.baidu.com

  • 最右侧 com：顶级域名（一级域）
  • 中间 baidu：二级域名（企业 / 机构自定义主体域名）
  • 左侧 www：主机名（子域名），标识服务器用途

DNS的迭代查询

  • 客户端向本地 DNS 服务器发送域名解析请求；
  • 本地 DNS 先查自身缓存，无记录则向根域名服务器发送迭代查询请求；
  • 根服务器只返回 .com 顶级域名服务器地址，不返回 baidu 的 IP；
  • 本地 DNS 拿着结果，向 .com 顶级域服务器再次发送迭代查询；
  • .com 服务器返回 baidu.com 权威域名服务器地址；
  • 本地 DNS 向 baidu.com 权威服务器发送迭代查询；
  • 权威服务器存储该域名记录，直接返回 www.baidu.com 对应的 IP；
  • 本地 DNS 将 IP 缓存，再把结果返回给客户端。
    特点：
  1. 查询压力由本地 DNS 承担：全部多次请求动作都由本地 DNS 完成，客户端只发 1 次请求、收 1 次应答；
  2. 权威服务器、根服务器、顶级域服务器只支持迭代查询，不提供递归服务，防止根服务器过载；

万维网（WWW）

万维网是运行在互联网之上、基于超文本的分布式多媒体信息服务系统，是互联网最核心的应用。
组成：客户端（浏览器）、Web服务器、传输协议（HTTP/HTTPS）、超文本标记语言HTML、超链接
特点：分布式、多媒体、交互式、松耦合
流程：浏览器输入地址 → DNS 域名解析为 IP→ 建立TCP连接 → HTTP/HTTPS 请求发送至 Web 服务器 → 服务器返回 HTML 网页资源 → 浏览器渲染页面展示给用户→ 资源缓存。

URL（统一资源定位符）

URL 是互联网上唯一标识某一个资源位置的标准化字符串，通俗来说：网页地址
协议://主机域名:端口/路径/文件名?查询参数#锚点

DHCP（动态主机配置协议）

功能：

  • 动态分配 IPv4 地址：从地址池自动分发空闲 IP，主机下线后回收 IP 重复利用，避免 IP 冲突。
  • 下发全套网络配置参数
    • 本机 IP 地址、子网掩码；
    • 默认网关（访问互联网出口）；
    • DNS 服务器地址（域名解析）；
    • IP 租用租期、续约时间。
  • 简化网络管理：管理员无需逐台设备手动配置网络，大量终端（手机、电脑、摄像头）即插即用。
  • 地址租期管理：IP 有使用时效，主机到期前自动续约，长期离线则回收 IP。
    工作原理：
  1. 新主机接入局域网，本机无 IP，广播发送 DHCP Discover 报文：
  2. 局域网内所有 DHCP 服务器收到 Discover 后，从地址池挑选空闲 IP，广播发送 DHCP Offer（携带预分配的 IP、子网掩码、租期等参数）
  3. 客户端选定最先收到的 Offer，广播发送 DHCP Request
  4. 目标 DHCP 服务器收到 Request 后，广播发送 DHCP ACK
    主机主动下线时，可单播发送 DHCP Release 报文，主动归还 IP 给服务器地址池。

FTP文件传输协议

应用层用于在网络两台主机之间上传、下载文件的标准协议，基于 TCP 可靠传输，专门负责文件共享与传输。区别于其他应用的特点：控制连接、数据连接

接收电子邮件的协议：POP3（接收）、SMAP（发送）

在浏览器输入网站URL按下回车直到首页显示-过程中用到的协议

应用层：DNS、HTTP
传输层：TCP
网络层：IP、ARP、ICMP（差错控制）
